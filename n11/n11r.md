## Challenging Strings:
String 110 was tricky because I was confused on how a branch can reach q2 and still fail. For 110, the branch that leaves q0 on the first 1 reaches q2 after reading 11, but the final 0 is still unread. That branch cannot continue. Keeping q0 as another possibility lets the machine make a later guess at the second 1, which leads to an accepting path.
